# Exercise 001: Hello World & Variables

**Difficulty:** Beginner

**Task:** 
Write a Python program that does the following:
1. Prints "Hello, Python World!"
2. Creates variables `name`, `age`, and `height` (use your own values)
3. Prints a sentence using all three variables.

**Expected Output:**
```
Hello, Python World!
My name is Tolu and I am 25 years old. My height is 1.75m.
```

**Hint:** Use f-strings for formatting.
