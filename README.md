# Comprehensive Python Exercises

A complete collection of **100+ Python exercises** progressing from beginner to advanced level.

## Structure
- `exercises/beginner/` — Basics to loops, functions
- `exercises/intermediate/` — OOP, data structures, file handling
- `exercises/advanced/` — Concurrency, decorators, algorithms, data science

## How to Use
1. Read the problem in each `.md` file
2. Create your solution in a `.py` file
3. Compare with the expected output

Happy coding!
